# Déclaration « Sécurité des données » (aide au remplissage)

Cette application ne transmet aucune donnée hors de l'appareil. Réponses attendues, à vérifier à la lecture du formulaire :

- L'application collecte-t-elle ou partage-t-elle des données utilisateur requises ? **Non** (les données restent sur l'appareil).
- Les données sont-elles chiffrées en transit ? Sans objet (aucune transmission).
- Les données stockées sur l'appareil sont chiffrées (AES-256) avec un code d'accès, et les sauvegardes exportées le sont aussi.
- Les utilisateurs peuvent-ils demander la suppression de leurs données ? Oui : suppression d'un dossier dans l'application, ou désinstallation.
- Politique de confidentialité : adresse de la page publiée à partir de `privacy-policy-fr.md`.

Si vous ajoutez plus tard une synchronisation en ligne ou un outil d'analyse, ces réponses devront être revues.
